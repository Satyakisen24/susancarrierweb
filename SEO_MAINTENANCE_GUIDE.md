## 🚨 Troubleshooting Rank Drops
If you notice a ranking fluctuation:
1. Check **Search Console > Manual Actions** (ensure no penalties).
2. Check for competitor changes in the local map pack.
3. Add 2 fresh client reviews on Google to re-stimulate local freshness signals.
4. Request a URL re-crawl in Google Search Console using the **URL Inspection** tool.
